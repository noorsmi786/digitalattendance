📲 Install Scanner on Phone

Since the server is running on your local school network (http://...), mobile Chrome disables the automatic popup. Use either method below:

⚡ Method 1: Add to Home Screen (5 Seconds)
  1. In Chrome on your phone, tap the Three Dots (⋮) in the top-right corner.
  2. Tap “Add to Home screen” (or Install app).
  3. Tap Add. Done! The SPHS Scanner app icon is on your phone.
🔧 Method 2: Enable Chrome's Disabled “Install App” Button

If you want Chrome's native Install button enabled for local WiFi:

  1. In phone Chrome address bar, open:
    chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Change dropdown to Enabled.
  3. In the box below, type: http://192.168.1.65:8000
  4. Tap Relaunch at the bottom.
